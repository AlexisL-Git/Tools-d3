Amis

Lien de telechargement

Adresse du paquet complet (480 Mo) chez ton hebergeur de fichiers. Les amis n'ont qu'un seul lien a connaitre : /api/telecharger — ils y collent leur cle, et seule une cle valide obtient l'adresse.

Coupe-circuit

Arrete TOUS les amis au prochain lancement, avec ce message. A utiliser le jour ou une mise a jour de Dofus rend l'outil dangereux.

Publier une version

Depose l'archive de code produite par la fabrication (code-x.y.z.tar.gz). L'empreinte est calculee par le serveur — tu n'as rien a recopier. Televerser ne change rien pour les amis : c'est activer qui bascule le manifeste.

Refus

Une version qu'un ami a ecartee parce qu'elle n'a pas demarre chez lui. En rouge quand elle porte sur la version actuellement active.
