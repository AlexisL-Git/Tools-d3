Le HUD, dans la langue de l app

La barre posee sur le jeu, refaite dans la langue de l app. Meme jetons, memes polices, memes regles : la forme avant la couleur, le jaune pour ce qui mene et ce qui tourne, un bloc inverse = une chose a faire, creux = eteint, plein = arme. Le fond ne suit pas le theme, c est le jeu. La barre, si.

Les pictos, RÉPL. et le passe-tour se cliquent : les etats tournent. Vahlkyr mene, Tacatak decroche, Brindille attend, Steamy n a pas d identifiant.
